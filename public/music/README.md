# Musik latar

Letakkan berkas audio di folder ini, lalu sesuaikan `music.localSrc` di `data/wedding.json`.

Contoh:

```json
"music": {
  "localSrc": "/music/background.mp3",
  "youtubeUrl": ""
}
```

`background.mp3` adalah pad ambient pendek yang dibuat secara prosedural (bukan rekaman komersial) agar tombol musik bisa diuji. Ganti dengan lagu yang Anda miliki lisensinya.

Jika `youtubeUrl` diisi, pemutar YouTube dipakai sebagai pengganti berkas lokal.
